# 底层逻辑 · 追根问底

一个训练「底层逻辑思维」的互动页：看见现象，不停在表层，一路追问它为什么存在、靠什么条件成立、条件变了会怎样，挖到最根本的原因。

## 四大模式

- **浏览**：什么是底层逻辑 · 七步追根法 · E-P-I-C 认知链条 · 6 个常见误区 · 修炼方法
- **追问**：选一个现象（内卷式竞争 / 刷短视频上瘾 / 一线城市房价），跟着走一遍七步追根
- **闯关**：16 道互动题（找根本原因 / 由表及里 / 反事实 / 必要条件 / E-P-I-C / 识破误区）
- **测一测**：8 项自评，测出你的底层逻辑思维等级

## 核心框架

- **七步追根法**：看见现象 → 为什么存在 → 存在条件 → 条件消失会怎样 → 影响因素 → 具体影响 → 最终后果
- **E-P-I-C**：Essence 本质洞察 → Pattern 模式提炼 → Implication 意涵衍生 → Context 语境重构

内容源自 93 篇「底层逻辑」研究文献（经济、教育、法律、科技、社会治理等领域）。

## 部署

纯静态单文件，直接打开 `index.html` 或部署到任意静态托管。
